

اسکریپت به‌صورت خودکار ابزارهای aria2 (برای دانلود سریع ۱۶ اتصاله) و p7zip-full (برای تقسیم فوری فایل) را نصب می‌کند.

در مقادیر بالای ۲ گیگابایت، فایل‌ها بدون فشار به CPU و رم به پارت‌های ۱.۸ گیگابایتی .7z.001 و ... تقسیم شده و ارسال می‌شوند.


🚀 دستور تک‌خطی برای اجرا روی سرور





```
bash <(curl -s https://raw.githubusercontent.com/2amir563/uploadfiletotelegrambozorgtaraz2gig/main/install.sh)
```

با اجرای این دستور در ترمینال سرور:
۱. پیش‌نیازها (aria2 و p7zip-full و python3-venv) نصب می‌شوند.
۲. مقادیر API_ID و API_HASH و BOT_TOKEN از شما گرفته می‌شود.


برای دریافت این ۳ مقدار، مراحل زیر را انجام دهید:

۱. دریافت API_ID و API_HASH (از سایت رسمی تلگرام)
این دو کد برای متصل شدن ربات شما به Pyrogram (ارسال فایل‌های تا ۲ گیگابایت) الزامی هستند:

وارد سایت رسمی تلگرام به آدرس my.telegram.org شوید.

شماره تلفن حساب تلگرام خود را همراه با کد کشور (مثلاً +98912...) وارد کنید.

یک کد تأیید در اپلیکیشن تلگرام برایتان ارسال می‌شود؛ آن را در سایت وارد کنید تا وارد پنل شوید.

روی گزینه API development tools کلیک کنید.

در فرم بازشده، دو فیلد اول (App title و Short name) را با یک اسم دلخواه به انگلیسی پر کنید (بقیه فیلدها را می‌توانید خالی بگذارید یا تغییر ندهید) و روی Create application کلیک کنید.

در صفحه جدید، دو عبارت App api_id (یک عدد چندرقمی) و App api_hash (یک رشته از حروف و اعداد) به شما نمایش داده می‌شود. آن‌ها را کپی و ذخیره کنید.

۲. دریافت BOT_TOKEN (از ربات FatherBot)
این توکن، شناسه اصلی ربات تلگرامی شماست:

در تلگرام ربات @BotFather را جستجو کرده و وارد آن شوید.

دستور /newbot را ارسال کنید.

یک نام دلخواه برای ربات خود بفرستید (مثلاً My File Downloader).

یک یوزرنیم (Username) انگلیسی ارسال کنید که حتماً در انتهای آن عبارت bot داشته باشد (مثلاً MyDownloader_123_bot).

در صورت موفقیت، پیام تبریکی دریافت می‌کنید که حاوی HTTP API Token است (کدی شبیه به 123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ). این همان BOT_TOKEN شماست.
